## Steps According to the New AWS Cognito Interface

**Step 1:** From the AWS Management Console search bar, find and access the **Amazon Cognito** service. 

**Step 2: Define your application**
* Under the **Application type** section, the system provides interface options. Since we are building a single-page application running on a web browser, select **Single-page application (SPA)**.
* In the **Name your application** field, name your application (e.g., `image-processor-web` or keep the default name generated by AWS like `My web app - ...`).

![Configuring SPA Application Type in the Cognito Dashboard](/Workshop/images/4/4.3/2.2.png)

**Step 3: Configure options**
* Scroll down to the **Options for sign-in identifiers** section, under sign-in attribute options, check the **Email** box (Ensuring users use their email address to register and sign in).
* Under **Self-registration**, keep the **Enable self-registration** box checked to allow users to automatically register new accounts via the Web interface.
* **Required attributes for sign-in**: Can be left blank or selected as needed.

![Configuring SPA Application Type in the Cognito Dashboard](/Workshop/images/4/4.3/2.3.png)

**Step 4: Add a return URL**
* **Return URL**: This is the redirection URL after a successful login. Since we run files locally on a computer or in a test environment, you can temporarily fill in `https://localhost` or `http://localhost` (or the Netlify URL after deployment). 
*(Note: You can completely change this parameter later after actual deployment).*

![Configuring SPA Application Type in the Cognito Dashboard](/Workshop/images/4/4.3/2.4.png)
